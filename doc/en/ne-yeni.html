What's New in Engelsiz Mail 1.8.2

  • An IMAP IDLE-based live monitoring system is now used for new-email notifications.
  • With live monitoring, the need to check for email at fixed minute intervals was removed; new messages can now be detected and announced in near real time.
  • Following the move to live monitoring, notification settings were simplified and the no-longer-needed check interval option was removed.
  • If the IDLE connection is interrupted, the add-on now attempts to restore the connection safely.
  • The add-on's overall speed was improved, with performance enhancements to email listing, cached reading, and background operations.
  • Overall stability was improved; background tasks, notifications, window lifecycle handling, and shutdown operations were made more robust.
  • Code optimization and maintenance reduced unnecessary work and improved concurrency safety and error handling.
  • Reading and background processing of emails with complex MIME structures were improved.
  • Compatibility with NVDA and current wxPython versions, as well as startup stability, was improved.
  • English language support was added. Menus, windows, buttons, notifications, and other user-interface text are now available in English.
  • Turkish and English User Guide and What's New documents were added; the appropriate document is opened automatically according to the NVDA interface language.
  • Turkish user-facing text was reviewed for terminology consistency, spelling, and clarity with screen readers.
