About

This add-on:

Has been developed to deliver a modern, rapid, and entirely accessible email client experience for blind and visually impaired NVDA screen reader users.

Completely eliminating the complex, cluttered, and cumbersome layout of standard webmail interfaces; it brings essential desktop email features directly into NVDA: reading and searching messages, composing rich formatted emails, replying, forwarding, background auto-saving of drafts, contact and signature management, archiving, moving, permanent deletion, conversation grouping, instant folder announcements of total and unread message counts, one-key switching between rich HTML web view and plain text (F7), inline image pasting directly at the cursor, creating tables with customizable rows and columns or pasting spreadsheets from Excel.

You can open the Engelsiz Mail main window using the shortcut NVDA + Shift + M or through the NVDA menu > Tools > Engelsiz Mail;
For feature requests, suggestions, or bug reports, please write to m.aykurt38@gmail.com.

1. Purpose of the Add-on

The core objective of Engelsiz Mail is to enable blind NVDA users to perform all email workflows in their Gmail accounts through a clean, fast, intuitive, and fully keyboard-accessible interface.

The add-on is designed to:

  1. Provide rapid and streamlined keyboard access to email folders.
  2. Announce total and unread message counts in folders clearly.
  3. Allow reading incoming emails both in original HTML web view (using NVDA browse mode) and clean plain text view with a single key (F7).
  4. Enable bold, italic, and underline character formatting with standard word processor simplicity without exposing raw HTML tags.
  5. Insert hyperlinks (Ctrl+K), clipboard images (Ctrl+V), and structured tables at the current cursor position.
  6. Silently auto-save drafts to Gmail's Drafts folder in the background to prevent data loss in case of unexpected shutdowns.
  7. Facilitate recipient selection via an integrated address book and contact management.
  8. Provide clear, unambiguous workflows for draft, archive, move, and deletion actions.
  9. Offer an optional inline preview in the email message list.
  10. Deliver real-time audio and spoken notifications when new messages arrive via IMAP IDLE.
  11. Make saving emails as TXT or EML and opening saved EML files effortless.
  12. Provide detailed connection diagnostics to guide users through troubleshooting.
  13. Offer customizable appearance settings tailored to individual visual preferences.

2. Highlights of the Current Version

In the current version:

  • HTML Email Reading View: Incoming emails can now be read in their authentic web layout accompanied by NVDA's virtual cursor (browse mode). Navigate effortlessly across headings (H), tables (T), lists (L), and links (K).
  • F7 Instant View Toggle: While reading an email, pressing F7 instantly flips between rich HTML web view and clean plain text view.
  • Natural Rich Text Composing: Compose emails with true WYSIWYG styling without seeing or hearing raw markup. Use Ctrl+B for bold, Ctrl+I for italic, and Ctrl+U for underline; verify typography anytime with NVDA+F.
  • Advanced Hyperlink Management (Ctrl+K): Add web links at the cursor, inspect or modify existing URLs, or remove links back to plain text with a single click.
  • Clipboard Image Pasting (Ctrl+V): Paste images directly from the clipboard (browser, Paint, screenshots, or File Explorer). An accessible description prompt allows screen reader users to assign descriptive alt text, and the image is embedded inline at that exact line.
  • Table Generation and Pasting: Insert structured tables from scratch with custom row and column counts (Ctrl+Shift+T / context menu) or paste tabular data directly from Excel and web pages. It renders as a full, styled HTML table on the recipient's screen.
  • Text Alignment (Left, Center, Right): Align selected lines or current paragraph to the left with Ctrl+L, center with Ctrl+E, and right with Ctrl+R, accompanied by NVDA speech announcements and clean inline styling.
  • Heading Levels (Heading 1 - Heading 6): Promote lines to hierarchical headings using Ctrl+Alt+1 .. Ctrl+Alt+6 and revert to regular body text with Ctrl+Alt+0; transforms into semantic `<h1>`-`<h6>` elements allowing rapid navigation with H in browse mode.
  • Bulleted and Numbered Lists: Cycle selected lines through bulleted list (`•`), numbered list (`1.`), or normal text with Ctrl+Shift+L; rendered as standard accessible `<ul>` and `<ol>` lists for recipients.
  • Background Auto-Saving of Drafts: While typing, changes are periodically synced to Gmail's server Drafts folder in the background without stealing keyboard focus or interrupting the user.
  • Smart Multipart MIME Delivery: Unformatted emails are dispatched as plain text, while messages with formatting, images, or tables are packaged as RFC-compliant multipart MIME bundles.
  • Enhanced Appearance Options: Select default message reading mode (HTML or Plain Text) from the View menu.

3. Security and Privacy

Engelsiz Mail never transmits your email address, Google app password, contact history, email contents, or attachments to any third-party server. All communication is established directly between your computer and official Google servers over encrypted TLS/SSL channels.

The add-on requires a dedicated Google App Password instead of your primary Google password. An App Password is a 16-character access key generated for Google accounts with 2-Step Verification enabled. The saved credentials on your local machine are encrypted using Windows DPAPI (Data Protection API) tied specifically to your user account.

Cached email headers, the contents of emails you have read, and downloaded attachments are stored in the local database and attachment folder and are not encrypted; they are protected only by your Windows user account's file permissions. On shared computers, choose to delete the local cache when you delete your account details, or reset the local database from the Settings menu.

4. Connecting a Google Account

To use Engelsiz Mail, 2-Step Verification must be enabled on your Google account and an app password must be created. The add-on connects to Gmail over secure IMAP (port 993) and SMTP (port 465 SSL / 587 STARTTLS).

Step-by-step setup:

  1. Sign in to your Google Account in your web browser and open the Security section.
  2. Verify that 2-Step Verification is turned on.
  3. Type "App passwords" in the search box to navigate to the App Passwords configuration page.
  4. Enter "Engelsiz Mail" as the app name and click Create.
  5. Copy the 16-character password generated by Google.
  6. In Engelsiz Mail, press Alt + B to open the Account Connection dialog.
  7. Enter your email address and paste the 16-character app password, then click Connect.

5. Main Window and Menu Structure

When the Engelsiz Mail main window opens, the title bar announces your connected Gmail address. The interface is optimized for screen reader ergonomics in the following Tab order:

  1. Folders List: Displays Inbox, All Mail, Sent Mail, Drafts, Trash, Spam, and custom user labels. While navigating with arrow keys, total and unread message counts are announced.
  2. Email Message List: Lists messages within the selected folder showing From, Subject, and Date. If preview is enabled, the snippet text is also read aloud.
  3. Menu Bar (Alt key): Organized main menus (File, Account, Email, View, Settings, and Help).

5.1. View Menu

  • Email view: Submenu to choose whether incoming emails open in HTML web view or classic plain text view by default. Contains Plain text view and HTML view.
  • Font...: Changes the font family used across Engelsiz Mail windows.
  • Font size...: Adjusts the font size.
  • Font style...: Selects regular, bold, italic, or bold italic styling.
  • Text color...: Changes text color inside the add-on windows.
  • Background color...: Changes window background color.
  • Use system colors: Adopts Windows high contrast and theme colors.
  • Reset to default view: Restores visual styles to defaults.

5.2. Settings Menu

  • Message count...: Sets how many emails are loaded per folder (between 1 and 100; default: 25).
  • Draft auto-save interval...: Configures how frequently composer changes are silently synced to Gmail Drafts (1-60 seconds; default: 60 seconds).
  • Notifications...: Configures new-email alerts, audio chimes, speech announcements, and custom sound effects.
  • Preview: Toggles short message snippet announcements in the email list.
  • Group conversations: Groups related email threads onto a single list item.
  • Show email content as is: When off (the default), images and external content in emails are hidden, so opening an email does not send a tracking request to the sender. When on, images and formatting are loaded from the internet. Scripts and frames are blocked in both cases.
  • Deletion: Configures confirmation dialogs prior to moving items to Trash or permanently purging.
  • Automatically save sent recipients: Saves outgoing email addresses into your local contact history.
  • Close add-on with Escape key: Enables or disables closing the main window with the Escape key.
  • Import/Export...: Backs up or restores account settings and history via a single ZIP archive.
  • Reset local database...: Clears the local SQLite cache and rebuilds message indexes from the server.

7. Folders and Email Reading Operations

The folders pane gives quick access to Gmail system folders (Inbox, All Mail, Sent Mail, Drafts, Trash, Spam) and custom labels. While navigating with arrow keys, NVDA reports the total and unread count for each folder.

7.1. Email Reading and HTML View

Pressing Enter on a message opens the reader dialog. The header fields (From, To, Cc, Date, Subject, Attachments count) precede the message body.

HTML Web View and NVDA Browse Mode: Messages can now be read in their original rich layout just like a web page. NVDA automatically switches into virtual buffer (browse mode), allowing quick navigation via single-letter keys: H for headings, T for tables, L for lists, and K for hyperlinks.

F7 Rapid View Toggle: Pressing F7 inside the reader instantly flips between HTML web view and clean plain text view. NVDA announces "Switched to HTML view" or "Switched to plain text view". Your preference is remembered across subsequent reads.

External Link Security: Clicking or pressing Enter on hyperlinks inside the HTML view opens the destination securely inside your default Windows internet browser, never inside the add-on window. Only http, https, and mailto links are opened.

Links in the Plain Text View (L, T, C): In the plain text view, links appear as ordinary text, and pressing Enter or clicking on a link does nothing. Use these keys instead: L moves to the next link and Shift+L to the previous one, and the address is read aloud. While the cursor is on a link, press T to open it in your default Windows internet browser, or C to copy its address to the clipboard. These keys open only http and https links.

Show email content as is: You can control how images and external content in emails are handled from the Settings menu with the Show email content as is option. When it is off (the default), images, external styles, and similar content are hidden, so opening an email never sends a tracking request to the sender. When it is on, images and formatting are loaded from the internet as the sender designed them. Scripts, frames, and forms are blocked in both cases. The setting applies the next time you open an email.

8. Composing Email, Formatting, Alignment, Headings, Lists, Images, and Tables

Press Ctrl + N or choose File > New email from the menu to open the compose window.

The window contains To, Cc (Alt+B), Bcc (Alt+G), Subject, Message body, and Attachments fields, traversed with the Tab key.

8.1. Rich Text and Character Formatting

While typing, you never encounter raw HTML markup (`<b>`, `<i>`, etc.). The text editor behaves just like Microsoft Word:

  • Bold Text (Ctrl+B): Select text and press Ctrl+B to toggle bold; NVDA announces the change. Pressing without selection sets the mode for upcoming text.
  • Italic Text (Ctrl+I): Applies or removes italic formatting.
  • Underline Text (Ctrl+U): Applies or removes underline formatting.
  • Format Inspection (NVDA+F): Pressing NVDA+F on any word announces its exact font style, bold, italic, or underline status.

8.2. Hyperlink Insertion, Editing, and Removal (Ctrl+K)

To insert a hyperlink:

  1. Select text (or place the cursor anywhere) and press Ctrl+K.
  2. Fill in the Display text and Web address (URL) fields, then press Enter.
  3. Only the human-readable text appears in the editor; no raw HTML is exposed.
  4. Editing and Inspecting Links: Pressing Ctrl+K while the cursor is inside an existing link opens the dialog in "Edit Link" mode with the URL pre-populated. Pressing Tab brings you directly to the "Remove Link" button to revert it back to normal text with one tap.

8.3. Clipboard Image Pasting (Ctrl+V)

You no longer need to browse through file dialogs to embed images in your message:

  1. Copy an image from a web browser (via right-click Copy Image), Paint, take a screenshot (PrintScreen), or copy an image file (PNG, JPG, JPEG, GIF, BMP, WEBP) from File Explorer with Ctrl+C.
  2. Place your cursor where the image belongs in Engelsiz Mail and press Ctrl+V.
  3. The system detects the image on the clipboard and displays the "Image Description" dialog.
  4. Enter an accessible description (e.g. Book Cover, School Yard) for screen readers and press Enter (leaving it blank assigns a default label).
  5. A clean inline placeholder appears at the cursor: [Image: Book Cover].
  6. When sent, the image is embedded directly into the email body as an inline MIME attachment (CID), rendered seamlessly on the recipient's screen.

8.4. Table Generation and Pasting

Engelsiz Mail supports two intuitive table workflows:

  1. Create Table from Scratch (Ctrl+Shift+T or Context Menu): Press Ctrl+Shift+T (or press the Applications key and choose Insert Table...). Specify row count, column count, and whether to include a header row. A clean, screen-reader-friendly template is placed at your cursor: 
    [Table Start]
| Header 1 | Header 2 |
| Cell 1   | Cell 2   |
| Cell 3   | Cell 4   |
[Table End]
    You can freely navigate and edit cells using arrow keys or add new rows.
  2. Paste Table from Clipboard (Ctrl+V): When copying cells from Microsoft Excel, Google Sheets, or web tables, pressing Ctrl+V automatically detects tabular data, converts it into an accessible table template, and NVDA announces "Table pasted.".
  3. Delivery: Upon dispatch, this template is translated into a fully styled, bordered HTML table for the recipient.

8.5. Text Alignment (Left, Center, Right)

You can quickly align selected text or the current line/paragraph with standard word processor simplicity:

  • Align Left (Ctrl+L): Reverts text to standard left-aligned layout. NVDA announces "Aligned left.".
  • Center (Ctrl+E): Centers text. Especially ideal for poetic stanzas, event announcements, or headlines. NVDA announces "Centered.".
  • Align Right (Ctrl+R): Aligns text to the right margin. Useful for dates, signatures, or footnotes. NVDA announces "Aligned right.".
  • Context Menu: For users who prefer menu navigation, an "Align" submenu is available in the right-click or Applications Key context menu.
  • HTML Output: In the sent message, centered lines are rendered as <p style="text-align: center;"> and right-aligned lines as <p style="text-align: right;">, ensuring perfect visual fidelity for the recipient.

8.6. Heading Levels (Heading 1 - Heading 6 and Normal Text)

Structure your email into hierarchical sections to make it fully accessible for screen reader users and webmail readers:

  • Heading Shortcuts (Ctrl+Alt+1 ... Ctrl+Alt+6): Promotes the current line directly to any heading level from Heading 1 (primary title) down to Heading 6. NVDA immediately announces "Heading 1 applied." .. "Heading 6 applied.". (Numpad 1..6 keys are also supported.)
  • Revert to Normal Text (Ctrl+Alt+0): Clears heading styling and converts the line back to a standard paragraph. NVDA announces "Normal text applied.".
  • Context Menu: All heading levels can be applied via the "Headings" submenu inside the editor context menu.
  • Semantic HTML and Virtual Cursor: Sent emails are structured with standard <h1> - <h6> tags. When reading, NVDA users can instantly jump between these headings using the H key in browse mode. If a heading is also centered (e.g. Ctrl+Alt+1 and Ctrl+E), both the heading tag and the alignment style are combined cleanly.

8.7. Creating Lists (Bulleted and Numbered Lists)

Convert sequential items or selected lines into formatted lists with a single keystroke:

  • Cycling List Shortcut (Ctrl+Shift+L):
    • 1st Press: Converts selected lines to a bulleted list (prefixes lines with • ). NVDA announces "Bulleted list applied.".
    • 2nd Press: Converts the list to a numbered list (prefixes lines with 1. , 2. , 3. ). NVDA announces "Numbered list applied.".
    • 3rd Press: Clears the list prefixes and reverts back to plain text. NVDA announces "List removed.".
  • Context Menu: Use the "List" submenu from the context menu to directly pick Bulleted List, Numbered List, or Remove List.
  • Screen Reader and HTML Compatibility: While drafting, literal • or 1. prefixes allow NVDA to speak bullets and numbers naturally while reading line by line. In the dispatched email, bulleted lines are rendered as <ul><li>...</li></ul> and numbered lines as <ol><li>...</li></ol>. In NVDA browse mode, recipients can jump straight to lists with L and navigate list items with I. For plain text clients, bullets and numbering remain cleanly formatted.

9. Draft Management and Automatic Saving

Drafts in Engelsiz Mail are not merely kept locally; they are synchronized directly with your Gmail server account.

9.1. Background Draft Auto-Save

While drafting or editing a message, changes are silently synced to Gmail's server Drafts folder at the interval defined under Settings > Draft auto-save interval... (default: 60 seconds).

Key advantages:

  • Typing focus is completely preserved without any interruption or cursor jumps.
  • Your work is safeguarded against unexpected power outages, system restarts, or accidental closures.
  • When no modifications are made, redundant network sync requests are skipped.

9.2. Editing, Sending, and Deleting Drafts

Opening a draft from the Drafts folder opens the compose window with all recipients, subject, text formatting, inline images, and attachments fully restored. Sending with Ctrl+Enter automatically removes the obsolete draft from the server; the Delete draft button moves it directly to Trash.

10. Archive and Move Operations

Selected emails can be archived with Alt+R or via Email > Send to archive. Manage custom archive folders with Email > Archive > Manage archive folders....

Use the context menu (Shift+F10) Move action to transfer messages between any custom label or the Inbox.

11. Attachments

In compose, reply, and forward windows, use the Attach file button to attach local files. Single and total attachment limits are 10 MB per email.

When an incoming message includes attachments, the reader window displays a Save attachments button, saving files into a dedicated subject-named folder inside your Downloads directory.

12. Check Connection (F9)

The Check connection... option on the Account menu (F9) tests internet reachability, Gmail IMAP/SMTP services, app password validity, and port connectivity, generating a comprehensive report to help resolve any configuration issues.

13. Saving and Opening EML Files

Save any selected email to disk as EML or TXT with Ctrl+S. Import and upload an existing EML file into your Gmail Inbox with Ctrl+O.

14. Notifications and Preview

Preview: When turned on in Settings, navigating the email list reads the first few sentences of each message following the subject line.

Live Notifications (IMAP IDLE): Engelsiz Mail listens to your Inbox in real time in the background. Incoming emails trigger instant audio chimes and speech notifications without polling delays. You may use built-in alerts or select custom WAV audio files.

15. Appearance Settings

Customize the interface typography, font sizes, styles, text colors, and window backgrounds via the View menu. Full support for Windows High Contrast and system themes ensures accessibility for low-vision users.

16. Sending Suggestions and Feedback

Under the Help menu, use Send suggestions and feedback... to send feature requests, thoughts, bug reports, or appreciations directly to the developer Mehmet Aykurt.

17. Customizing the Opening Shortcut

To change the default NVDA + Shift + M shortcut:

  1. Open NVDA Menu > Preferences > Input Gestures.
  2. Expand the Engelsiz Mail category.
  3. Select "Opens Engelsiz Mail main window", click Add, and press your preferred key combination.

18. Known Limitations and Important Notes

  • Engelsiz Mail connects via the Gmail infrastructure; 2-Step Verification and an App Password are required on your Google account.
  • Single and cumulative attachment sizes are capped at 10 MB.
  • If internet connectivity drops, background notifications pause and reconnect automatically once connection is restored.
