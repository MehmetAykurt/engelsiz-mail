What's New in Engelsiz Mail 2026.11.19

  • Comprehensive HTML Email & Rich Content Support:
    • HTML Email Reading View: Incoming emails can now be viewed with their original layout and styling using NVDA's virtual cursor (browse mode). Navigate effortlessly between headings (H), tables (T), lists (L), and hyperlinks (K).
    • Rapid View Toggle (F7): Pressing F7 inside the email reader instantly switches back and forth between rich HTML web view and clean plain text view.
    • Rich Text Composing: Compose messages with true WYSIWYG simplicity without dealing with raw HTML markup. Use Ctrl+B for bold, Ctrl+I for italic, and Ctrl+U for underline; verify typography with NVDA+F.
    • Advanced Hyperlink Management (Ctrl+K): Easily insert web hyperlinks, inspect/modify existing URLs, or convert links back to plain text with the "Remove Link" button.
    • Clipboard Image Pasting (Ctrl+V): Paste images directly into the message body from web browsers, Paint, screenshots, or File Explorer. An accessible description dialog allows screen reader users to set descriptive alt text, embedding the image inline (CID).
    • Table Creation & Pasting: Insert structured tables from scratch (Ctrl+Shift+T / context menu) with customizable row/column counts, or paste copied spreadsheet data from Microsoft Excel and web pages via Ctrl+V.
    • Text Alignment (Left, Center, Right): Align selected lines or current paragraph to the left with Ctrl+L, center with Ctrl+E, and right with Ctrl+R.
    • Heading Levels (Heading 1 - Heading 6): Promote lines to heading levels using Ctrl+Alt+1 through Ctrl+Alt+6 and revert back to normal paragraph with Ctrl+Alt+0; automatically converts to semantic `<h1>`-`<h6>` headings for browse mode navigation (H).
    • Bulleted & Numbered Lists: Cycle through bulleted list (`•`), numbered list (`1.`), and plain text using Ctrl+Shift+L; rendered as standard `<ul>` and `<ol>` lists for recipients.
    • Smart Multipart MIME Delivery: Messages with styling, images, or tables are dispatched as RFC-compliant multipart MIME packages, ensuring perfect visual rendering for all recipients.
  • Automatic Draft Saving: To prevent data loss from accidental closures, system restarts, or power interruptions while composing, drafts are now automatically and silently synced to Gmail's Drafts folder in the background without stealing focus (configurable between 1–60 seconds in Settings; default: 60 seconds).
  • The add-on's overall execution speed was improved, with performance enhancements across email listing, cached reading, and background tasks.
  • Overall stability was enhanced; background tasks, notifications, window lifecycles, and shutdown routines were made significantly more reliable.
  • Code optimization and refactoring reduced redundant operations, improving concurrency safety and error handling.
  • Reading and background processing of emails with complex MIME structures were improved.
  • Compatibility with NVDA and current wxPython versions, as well as startup stability, was improved.
  • Security and privacy:
    • Email content is now cleaned before it is displayed. Scripts, frames, forms, and redirects are blocked. By default, images and external content are hidden, so opening an email does not send a tracking request to the sender.
    • New setting: "Show email content as is" (Settings menu). When on, images and formatting are loaded from the internet. Scripts and frames stay blocked in that case too.
    • Links inside emails open only if they use http, https, or mailto. Link types that could launch files or programs on your computer are now blocked.
    • When you delete your account details, you are now asked whether to delete the local email cache as well. The guide now states that the cache is not encrypted and how to clear it on shared computers.
  • Data safety:
    • When another program (for example an antivirus scanner) temporarily locks the settings file, your account details and settings are no longer lost or overwritten with empty data. The same protection applies to contacts and address history.
    • Deleting from Trash always asks for the permanent deletion confirmation, even if you turned off the ordinary delete confirmation.
    • If an "Empty Trash" or "Empty Spam" request given while offline is processed hours later, emails that arrived in the folder after your request are not deleted.
    • When the contact limit (1000) is reached, you now get a warning instead of extra contacts being silently dropped.
    • The archive deletion confirmation now states clearly that the emails in the archive are not deleted.
  • Composing email:
    • Hyperlinks, headings, and alignment stay in the right place as you edit the text. A situation that could make a hyperlink read as two lines in a screen reader was fixed.
    • You are asked for confirmation before sending an email with an empty subject.
    • Inline images in an email saved as a draft are now preserved. When you open a draft that contains formatting (such as links, images, or headings), you are warned that editing and saving it in the add-on will remove that formatting.
    • A 10 MB limit and a clear warning were added for images pasted from the clipboard.
    • If "First row is a table header" is unchecked, the table is now really sent without a header.
    • Very long attachment file names keep their file extension; names reserved by Windows, such as CON and NUL, are saved safely.
    • When saving attachments from several emails, you are now told if some of them could not be retrieved.
    • If the app password is wrong, sending is no longer retried with a second method, which avoids unnecessary failed sign-in alerts on your Google account.
  • Speed and stability:
    • Opening emails is faster. When you press Enter, the email opens right away without waiting for NVDA to finish speaking; the "viewing" announcement was removed. The HTML view is prepared only when it is needed.
    • The cache was extended. The newest 150 emails of every folder are kept ready in the background, and missing ones are completed when you open a folder. The number of emails shown in the list is unchanged (default 25, up to 100). As you delete or move emails, the next ones are already ready.
    • A single email whose header cannot be retrieved from the server no longer stops the whole folder from synchronizing.
    • In the archive, connect account, number of emails, and notification settings dialogs, Enter in a text field now confirms the dialog.
    • Unnecessary error log entries produced when windows close or connections are cut on purpose were reduced.
